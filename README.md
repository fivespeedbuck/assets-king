# 资产大王

<img src="app/src/main/res/drawable-nodpi/ic_launcher.png" width="160" alt="资产大王图标">

钱从哪里来，又到哪里去。

资产大王是一款本地优先的安卓自动记账与资产管理应用。它计划通过 Android 通知读取银行卡、微信、支付宝和花呗动账信息；不登录手机银行，不收集银行卡密码，第一版不依赖服务器或账号系统。

## 当前版本

GitHub Release：[资产大王 v0.1.1](https://github.com/fivespeedbuck/assets-king/releases/tag/v0.1.1)。本版本恢复贷款页新增信用卡入口，修复银行短信商户/支付渠道识别、贷款利率精度与统一月供输入，并补充商户映射删除。

## 当前可用功能

- 本地 Room 数据库，预置招商银行、宁波银行、广发信用卡和花呗账户
- 手动记录支出、收入、退款、转账和信用账户还款
- 按商户关键词自动分类，无法确定时保持“未分类”
- 资产、信用卡和贷款账户采用不同的余额变化规则
- 信用卡和花呗还款按账户转移处理，不重复计入支出
- 自定义贷款还款计划：每期本金、利息、费用、日期和状态
- 按真实放款日及每期现金流计算总利息、总费用、总还款和实际年化
- 系统绑定的 `NotificationListenerService` 入口，收到通知后先保存原文
- 通知权限状态提示，可直接跳转系统设置
- 银行短信商户名会去除“支付宝-”“微信-”等渠道前缀，只保留商户主体
- 银行余额不一致时可在流水编辑器直接选择“以通知余额为准”或“以当前流水为准”
- 离开应用不足 10 分钟返回不重复要求解锁，超时后自动进入隐秘模式

通知解析、去重、待确认箱和短信补扫已接入；当前版本仍坚持先保存证据，待确认前不会根据未验证通知自动修改余额。

## 模块

```text
app             Compose 界面、通知监听入口
core-model      账户、流水、转账、通知、贷款计划模型
core-ledger     账务规则、自动分类、贷款成本计算
core-database   Room 实体、DAO 和本地仓库
```

## 核心账务约定

- 资产账户余额越大代表可用资金越多
- 信用卡、贷款账户余额越大代表待还负债越多
- 信用卡或花呗还款是 `Transfer`，不生成第二笔支出
- 待确认和忽略流水不会修改账户余额
- 所有金额以“分”为单位保存，避免浮点误差
- 自动分类必须可解释；没有命中规则时不硬猜

## 后台采集边界

资产大王固定排除在系统最近任务列表之外，不提供可上划移除的应用卡片。OriginOS 仍可能要求开启自启动、通知读取和后台运行权限；若用户在系统设置中“强制停止”应用，Android 会冻结整个应用，必须再次手动打开后才能恢复，普通第三方应用无法绕过此限制。

## 构建

需要 JDK 17 和 Android SDK 35。项目已包含 Gradle Wrapper：

```text
gradlew.bat :core-ledger:test assembleDebug
```

调试 APK 输出到 `app/build/outputs/apk/debug/app-debug.apk`。
